# Web Kitaplığı

Bu proje, React kullanılarak oluşturulmuş küçük bir web kitaplığı uygulamasıdır.  
Kullanıcılar kitaplar arasında arama yapabilir, kategoriye göre filtreleyebilir ve kitapları favorilere ekleyip çıkarabilir. Favoriler ve arama geçmişi `localStorage` ile kalıcıdır.  
Projeyi canlı olarak görmek için [buraya tıklayabilirsiniz](https://web-kitapligi.vercel.app/).

---

## Özellikler
- Kitaplar arasında arama yapabilme
- Kategoriye göre filtreleme
- Favorilere ekleme ve çıkarma
- `localStorage` ile veri kalıcılığı

---

## Kullanılan Teknolojiler
- React (Vite)
- JavaScript (ES6)
- HTML / CSS
